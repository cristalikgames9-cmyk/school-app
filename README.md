# Онлайн-школа — 1 класс

Простой сайт: предметы → уроки (видео с YouTube) → домашнее задание из 7 задач
с проверкой (верно / частично верно / неверно) и итогом в конце.

## Запуск локально

Нужен Node.js (у тебя уже установлен).

```bash
npm install
npm start
```

Открой в браузере: http://localhost:3000

## Как добавить свои уроки

Всё содержимое лежит в папке `data/` в обычных JSON-файлах — код трогать не надо.

1. **`data/subjects.json`** — список предметов (иконка, цвет, id).
2. **`data/lessons.json`** — уроки по каждому предмету. У каждого урока:
   - `id` — уникальный, используется в ссылках и в файле домашек;
   - `videoId` — это часть ссылки на YouTube-видео. Например, для
     `https://www.youtube.com/watch?v=ABC123xyz` нужно вставить `ABC123xyz`.
3. **`data/homeworks.json`** — домашние задания. Ключ объекта = `id` урока,
   значение — массив из 7 задач:
   ```json
   {
     "id": "q1",
     "question": "Текст вопроса",
     "type": "single",       // "single" — один верный ответ, "multiple" — несколько
     "options": ["А", "Б", "В"],
     "correct": [1]           // индексы верных вариантов (с нуля)
   }
   ```
   Для `type: "multiple"` при частичном совпадении выбранных ответов
   с верными автоматически ставится «частично верно».

### Картинки в заданиях (по ссылке, без загрузки файлов в проект)

Можно добавить картинку к самому вопросу и/или картинку к каждому варианту
ответа — просто вставь прямую ссылку на изображение (заканчивается на
`.jpg`, `.png`, `.webp` и т.п.). Файлы никуда загружать не нужно.

**Картинка к вопросу:**
```json
{
  "id": "q1",
  "question": "Сколько яблок на картинке?",
  "image": "https://example.com/images/apple.png",
  "type": "single",
  "options": ["1", "2", "3"],
  "correct": [0]
}
```

**Картинки в вариантах ответа** — вместо простой строки укажи объект
`{ "text": "...", "image": "..." }`:
```json
{
  "id": "q2",
  "question": "Отметь картинку, где нарисован круг.",
  "type": "single",
  "options": [
    { "text": "Круг", "image": "https://example.com/images/circle.png" },
    { "text": "Квадрат", "image": "https://example.com/images/square.png" },
    { "text": "Треугольник", "image": "https://example.com/images/triangle.png" }
  ],
  "correct": [0]
}
```

Варианты с картинками и без можно свободно смешивать в одном списке
`options`, а обычный текст (просто строка `"Круг"`) по-прежнему работает —
менять уже готовые задания не нужно.

Где брать ссылки на картинки:
- Любой сайт с бесплатными изображениями (Pixabay, Unsplash, Flaticon и т.п.) —
  открой картинку, нажми правой кнопкой → «Копировать адрес изображения»
  (Copy image address), это и есть ссылка для `"image"`.
- Загрузить свою картинку на бесплатный хостинг картинок (например,
  imgur.com — без регистрации) и скопировать оттуда прямую ссылку.
- Главное — ссылка должна вести **прямо на файл картинки**, а не на страницу
  сайта с картинкой внутри.

После правки JSON достаточно перезапустить сервер (`npm start`).

## Как устроено сохранение результатов

- Каждый ученик при первом заходе вводит имя — оно и случайный `studentId`
  сохраняются в localStorage браузера.
- После прохождения всех 7 задач результат отправляется на сервер
  (`POST /api/results`) и дописывается в файл `data/results.json`.
- Посмотреть последнюю попытку конкретного ученика по уроку можно через
  `GET /api/results/:studentId/:lessonId`.

⚠️ **Важно про бесплатный хостинг.** Многие бесплатные хостинги (Render Free,
Railway Free, Glitch и т.п.) либо "усыпляют" сервер при простое (это не страшно —
он проснётся при заходе, только чуть медленнее), либо **очищают диск при каждом
новом деплое/перезапуске контейнера**. Это значит, что файл `data/results.json`
может обнулиться. Для маленького проекта "для узкого круга" это обычно не
критично, но если результаты важно не терять, есть два простых варианта:

1. Использовать хостинг с постоянным (persistent) диском — например, Render
   позволяет подключить Persistent Disk даже на некоторых бесплатных/дешёвых
   планах — тогда `data/results.json` переживёт перезапуски.
2. Заменить хранение результатов на бесплатную облачную БД, например
   **MongoDB Atlas Free Tier** — она бесплатна и не привязана к диску сервера.
   Логика в `server.js` в блоке `readResults` / `writeResults` — их достаточно
   заменить на пару запросов к базе, остальной код менять не нужно.

## Деплой (например, Render.com, бесплатный план)

1. Залей этот проект в GitHub-репозиторий.
2. На Render: **New → Web Service** → подключи репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. После деплоя Render сам создаст публичную ссылку вида
   `https://твой-проект.onrender.com`.

## Структура проекта

```
school-app/
  server.js              — Express-сервер и API
  data/
    subjects.json         — предметы
    lessons.json           — уроки (видео) по предметам
    homeworks.json          — домашние задания (7 задач на урок)
    results.json           — сюда пишутся результаты учеников
  public/
    index.html              — главная: список предметов
    subject.html              — список уроков предмета
    lesson.html                 — плеер + переход к ДЗ
    homework.html                 — прохождение 7 задач и итог
    css/style.css                  — оформление
    js/                              — вся логика страниц
```

## Что можно добавить дальше

- Отдельную "кабинет учителя" страницу со сводкой из `results.json`.
- Больше уроков — просто дописывай объекты в JSON.
- Прогресс-бар по всему курсу (сколько уроков пройдено).
