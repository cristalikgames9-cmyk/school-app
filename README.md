# Онлайн-школа — 1 класс (v3, уроки — отдельными файлами)

Эта версия хранит уроки так, как тебе удобно: `data/lessons/<предмет>/*.txt`,
каждый файл — один урок целиком, включая задания внутри. Отдельного
`homeworks.json` больше нет — он не нужен.

## Структура данных

```
data/
  subjects.json          — список предметов (не менялся)
  lessons/
    math/
      math-1.txt           — урок + его задания одним файлом
    russian/
      russian-1.txt
    lit/
      reading-1.txt
    world/
      world-1.txt
    izo/                    — пока пусто (папка есть, уроков нет)
    training/                — пока пусто
```

Название папки — просто для порядка на диске, реальная привязка урока к
предмету идёт по полю `"subjectId"` внутри самого файла.

⚠️ **Главное правило: `"id"` урока должен быть уникальным на весь сайт**, а
не только внутри предмета — потому что страница `/lesson.html?id=...` не
знает, из какой он папки, и ищет по всем сразу. Если два урока в разных
предметах случайно получат одинаковый `id` — откроется первый найденный, не
тот что нужен. Сервер это отследит и **напишет предупреждение в консоль**
(не упадёт), но лучше не допускать: называй id с префиксом предмета —
`math-1`, `math-2`, `russian-1` и т.д.

Если хочешь, чтобы уроки внутри предмета шли по порядку — называй сами
**файлы** с номерами: `01-chisla.txt`, `02-figury.txt` (сервер читает файлы
в алфавитном порядке).

## Формат одного файла урока

```json
{
  "id": "math-2",
  "subjectId": "math",
  "title": "Урок 2. Число и цифра 2",
  "videoUrl": "https://kinescope.io/embed/AbCdEfGhIjKlMnOp12",
  "content": "Текст-описание урока, который увидит ученик под видео.",
  "tasks": [
    {
      "id": "t1",
      "type": "normal",
      "question": "Сколько будет 1 + 1?",
      "image": null,
      "options": [
        { "id": "A", "text": "1" },
        { "id": "B", "text": "2" },
        { "id": "C", "text": "3" }
      ],
      "correctAnswer": "B"
    },
    {
      "id": "t2",
      "type": "multiple",
      "question": "Отметь ВСЕ картинки, где предметов ровно два.",
      "image": null,
      "options": [
        { "id": "A", "text": "2 яблока" },
        { "id": "B", "text": "1 груша" },
        { "id": "C", "text": "2 мяча" }
      ],
      "correctAnswer": ["A", "C"]
    },
    {
      "id": "t3",
      "type": "text",
      "question": "Напиши число, которое идёт после 1.",
      "image": null,
      "correctAnswer": "2"
    }
  ]
}
```

**`videoUrl`** — это уже готовая embed-ссылка, вставляется в `<iframe>` как
есть, ничего собирать не нужно. Для Kinescope: в кабинете открой видео →
«Поделиться» / «Embed» → скопируй ссылку вида
`https://kinescope.io/embed/AbCdEfGhIjKlMnOp12` целиком.

**Типы задач (`type`):**
- `"normal"` — один правильный вариант. `correctAnswer` — id варианта, например `"B"`.
- `"multiple"` — несколько правильных вариантов (чекбоксы). `correctAnswer` —
  массив id, например `["A", "C"]`. Если ученик отметит только часть верных —
  засчитается «частично верно».
- `"text"` — свободный ответ (поле ввода вместо вариантов). `correctAnswer` —
  строка (сравнение без учёта регистра и лишних пробелов), либо массив строк,
  если подходит несколько формулировок: `"correctAnswer": ["2", "два"]`.

**`image`** — необязательное поле, ссылка на картинку к вопросу (или `null`).

После добавления/правки файла урока — просто обнови страницу в браузере,
сервер перечитывает файлы (с кэшем на 3 секунды, поэтому изменения видно
почти сразу, перезапускать `npm start` не обязательно).

## Что нужно сделать в Supabase (обязательно)

Зайди в свой проект на supabase.com → **SQL Editor** → выполни:

```sql
-- Таблица users у тебя, судя по всему, уже есть (там уже bcrypt-хеши).
-- Если вдруг её нет:
create table if not exists users (
  id bigint generated always as identity primary key,
  username text unique not null,
  password text not null, -- bcrypt-хеш, не сам пароль
  created_at timestamptz default now()
);

-- Новая таблица — сюда пишутся ответы на домашние задания
create table if not exists answers (
  id bigint generated always as identity primary key,
  user_id bigint not null references users(id) on delete cascade,
  lesson_id text not null,
  question_id text not null,
  status text not null, -- correct | partial | incorrect
  selected_options jsonb not null default '[]'::jsonb,
  created_at timestamptz default now(),
  unique (user_id, lesson_id, question_id)
);

-- Проект небольшой, для узкого круга, своя система входа (не Supabase Auth) —
-- поэтому проще отключить Row Level Security:
alter table users disable row level security;
alter table answers disable row level security;
```

⚠️ Если у таблицы `users` поле `id` не `bigint`, а `uuid` — поменяй
`user_id bigint` на `user_id uuid` в SQL выше.

## Настройка `.env`

Уже заполнен твоими ключами Supabase + сгенерированным `COOKIE_SECRET`
(секрет для подписи куки сессии — без него куку можно подделать вручную и
зайти в чужой аккаунт). Ничего менять не обязательно, но если хочешь
надёжнее — возьми `service_role` ключ в Supabase (Project Settings → API) и
подставь в `SUPABASE_KEY`: он работает только на сервере, в браузер никогда
не попадает, и не зависит от RLS.

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000` — редиректнёт на `/login.html`.

## Что было починено при переходе на файловую схему

- Загрузчик уроков теперь ищет по всем папкам `data/lessons/*/`, а не читает
  один общий `lessons.json`.
- Роуты `/api/subjects/:id`, `/api/lessons/:id`, `/api/homework/:lessonId`
  переписаны под новый источник данных.
- Проверка ответов в ДЗ переписана под новую схему: `correctAnswer` — id
  варианта (буква), а не индекс, плюс добавлена поддержка типа `"text"`
  (свободный ответ) и `"multiple"` (частичный зачёт).
- Прогресс на главной странице считает урок пройденным, если отвечены все
  его `tasks` (столько же записей в Supabase, сколько задач в файле урока).
- Твои 4 существующих урока (математика, чтение, русский, окружающий мир) —
  автоматически перенесены из старой схемы в новую, ничего не потерялось.
  Видео пока не привязано (`"videoUrl": "PASTE_EMBED_URL_HERE"`) — вставь
  свои ссылки.
- Проверка на задвоенные `id` урока — предупреждение в консоли сервера, а не
  тихая поломка.
